## Known Limitations (Phase 1)

- Semantic retrieval uses hashing embeddings, not a trained embedding model: it captures
  vocabulary overlap, not deep semantics. Quality is measurable once EVAL-005 exists.
- Non-Python chunking is heuristic (brace balancing), not tree-sitter. Accurate on the
  tested samples; malformed sources fall back to line windows.
- `aica ask`/`complete` are advisory: they do not edit files. Autonomous edit loops are
  Phase 2 (AG-001..004).
- Execution is subprocess-isolated only (Entry 012).
- Audit is JSONL; ADM-007 search and ADM-009 retention are Phase 4.

### Entry 014
- Date: 2026-09-22
- Decision: The remaining Phase 1 capabilities were completed as **advisory** features that
  return a proposal instead of applying it: `gen-tests` returns a test file but never writes
  one, `commit-message` returns a message but never commits, `debug` returns a diagnosis but

  their guards, approval gates and audit rather than a second, unguarded path.

### Entry 015
- Date: 2026-09-22
- Decision: A generated commit message is only used when it passes `validate_commit_message`;
  otherwise a deterministic diff-stat message is used and **marked** as not model-generated
  (`CommitMessage.generated`). Rationale: GIT-006 asks for meaningful messages, and a silent
  fallback that looks model-written would be the same class of false claim TEST-009 forbids.
- Status: Active.
